# 🏦 Sistema Bancário em Java (Console)

## 📌 Descrição

Projeto desenvolvido em **Java 17** com foco na prática de **Programação Orientada a Objetos (POO)** e na evolução contínua dos estudos. O sistema foi aprimorado gradualmente conforme novos conceitos foram sendo aprendidos durante a Maratona Java, aplicando boas práticas de organização, reutilização de código e refatoração.

O sistema simula operações bancárias por meio de um menu interativo no console, permitindo o gerenciamento de múltiplos clientes e suas contas bancárias.

---

# 🚀 Funcionalidades

* ✅ Cadastro de múltiplos clientes
* ✅ Cadastro de cliente com nome e CPF
* ✅ Validação de CPF duplicado
* ✅ Criação de conta Corrente e Poupança
* ✅ Numeração automática das contas
* ✅ Depósitos
* ✅ Saques
* ✅ Transferências entre contas
* ✅ Consulta de cliente por CPF
* ✅ Listagem de todos os clientes
* ✅ Validação de saldo insuficiente
* ✅ Validação de valores informados pelo usuário
* ✅ Interface interativa via console
